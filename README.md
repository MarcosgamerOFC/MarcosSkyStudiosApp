## ⚙️ Diretrizes da MarcosSkyStudios

A **MarcosSkyStudios** é um estúdio independente brasileiro que recusa a ganância corporativa e as taxas abusivas de mercado. Este projeto usa a arqueologia digital, os glitches e a quebra da quarta parede como linguagem narrativa.

* **Distribuição Aberta:** Códigos, assets e registros mantidos abertamente no GitHub.
* **Independência Criativa:** Sem executivos, sem cortes de orçamento e sem censura.
